Netflix Clone

About the Project
This project is a web application that replicates the user interface of the Netflix landing page. It features a responsive hero section prompting user email registration, a sign-in portal, and a dynamic background showcasing a catalog of popular films and TV programs like Stranger Things, Money Heist, and Bridgerton. 

Tech Stack
* Frontend: React
* State Management: Redux
* Deployment/Hosting: Vercel
